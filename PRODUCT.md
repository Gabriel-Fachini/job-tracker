# Product

## Register

product

## Users

One user: the developer. A software engineer actively job-hunting, using this tool daily to manage leads sourced by the radar, track applications, and maintain a profile. Context: focused work sessions, dark environment, desktop browser. Primary task on any screen is reviewing and acting on job leads, not exploring the tool.

## Product Purpose

A personal job-hunting operations center. The radar surfaces leads from company boards; the user triages them, tracks applications, and maintains a resume profile. Success means moving from raw leads to submitted applications with minimal friction and maximum clarity on pipeline state.

## Brand Personality

Sharp, focused, purposeful. The tool should feel like something built for the developer by the developer — opinionated, efficient, with quiet craft. Warm but not cozy; professional but not corporate. Personality comes through spacing, typography weight contrast, and deliberate detail — not decoration.

## Anti-references

- Generic SaaS dashboards: Bootstrap-style gray card grids, hero metrics, blue primary buttons, identical card columns, "enterprise" roundedness.
- Recruitment platform UIs (Greenhouse, LinkedIn, Indeed): corporate job-board aesthetic, dense tables with HR-department energy.
- Over-engineered portfolio tools: gradient-heavy, animation-first, substance-light.

## Design Principles

1. **Earn every pixel.** Nothing decorative. Every visual element carries information or guides action.
2. **Workflow over aesthetics.** Optimize for the repeated daily use case: triage leads, update status, write notes. Reduce friction at these points even if it makes the UI less "designed".
3. **Quiet confidence.** Restrained color, strong typography hierarchy. The tool knows what it is; it doesn't need to announce itself.
4. **Personal, not corporate.** This is a hand-built tool. It should feel that way — precise but not cold, functional but with visible craft in the details.
5. **Dark-native.** Dark mode is not a skin. Colors, contrast, and motion are designed for dark-first. Light mode is not planned.

## Accessibility & Inclusion

Solo tool, pragmatic baseline. Keyboard navigation for power use (tab through leads, keyboard shortcuts where natural). Contrast sufficient for extended daily use without strain. Reduced motion respected via `prefers-reduced-motion`.
